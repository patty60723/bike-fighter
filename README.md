# bike-fighter

YouBike 站借不到車、還不了車的時候，按按鈕發洩怒氣；這些怒氣同時累積成各站供需不足的證據。

- 網頁：[index.html](index.html)（v1.2，單一 HTML 檔，不需要建置）
- 後端：[worker/](worker/)（Cloudflare Worker + D1 資料庫）
- 可行性報告：[docs/feasibility-report.md](docs/feasibility-report.md)

## 功能

- **附近站點地圖**：台北市＋新北市站點依可借車數（或可還位數）上色，可切換「看借車／看還車」。GPS 定位後自動選最近的站；手動選的站會保持，直到你走離 200 公尺或按 ◎。
- **搜尋站點**：地圖上方的搜尋框可以打站名或行政區（例如「市政府」「板橋」），「台」「臺」都能找到。結果附即時借、還數量，選了地圖就移過去。
- **常用站點**：在選中的站旁按「☆ 加入常用」，最多 10 站。常用站列在地圖下方，附即時借、還數量；下拉選單也會排在最前面。收藏只存在這支手機。
- **在站驗證**：要在站點 100 公尺內才能開始一批怒氣。中途離開可以打完這批，下一批要回到站點。
- **怒氣連擊**：每下間隔不超過 3 秒算同一批，停手 3 秒送出，等級 = ⌊log₂(點擊數)⌋。
  - 只按 1 下算誤觸
  - 每批送出後冷卻 30 秒
  - 長按、按住鍵盤不會連發
  - 間隔不到 0.06 秒的點擊不算
- **伺服器驗證**：每一批都會送到後端，再檢查一次距離、冷卻、手速、移動速度和當下車位，通過才記錄。
- **空站魔王**：站點變成 0 輛（或 0 位）時出現。最近 10 分鐘有 20 人在現場送出怒氣就打倒。人數、等級都是真實資料。
- **需求紀錄**：每次空站、滿站恢復時，記下持續多久、多少人受影響、是否疑似調度。
- **統計切換**：「怒氣等級」與「點擊次數」兩種顯示。

## 執行方式

直接用瀏覽器打開 `index.html`，或用任何靜態網站伺服器提供這個檔案。

- **後端連得上**：站點、統計、空站魔王、需求紀錄都來自後端，標題旁顯示「即時資料・已連線」。
- **後端連不上**：直接讀台北市資料（新北市仍經由後端的 `/ntpc` 轉發），其他人的資料改成模擬，顯示「即時資料・離線」。
- **都讀不到**：示範模式，用範例站點與空白底圖。拖曳地圖上的藍點可以模擬走動。

後端的部署與本機開發方式見 [worker/README.md](worker/README.md)。

### 用 GitHub Pages 發佈

1. 到 repo 的 Settings → Pages。
2. Source 選「Deploy from a branch」，分支選 `main`，資料夾選 `/ (root)`。
3. 存檔後，網址是 `https://patty60723.github.io/bike-fighter/`。

## 已知限制

- 沒有帳號：用瀏覽器自己產生的匿名代號計算人次。清掉瀏覽器資料就會換新代號，可能被拿來繞過冷卻。
- 常用站點、自己送出的紀錄只存在這支手機的瀏覽器。
- 車位資料來自市府開放資料，會比官方 App 慢一點；選中站點下方會顯示資料時間。
