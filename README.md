# bike-fighter

YouBike 站借不到車、還不了車的時候，按按鈕發洩怒氣；這些怒氣同時累積成各站供需不足的證據。

- 可行性報告：[docs/feasibility-report.md](docs/feasibility-report.md)
- 網頁原型：[index.html](index.html)（v0.4，單一 HTML 檔，不需要建置）

## 原型功能

- **附近站點地圖**：站點依可借車數（或可還位數）上色，可切換「看借車／看還車」。
- **在站驗證**：要在站點 100 公尺內才能開始一批怒氣。中途離開可以打完這批，下一批要回到站點。
- **怒氣連擊**：每下間隔不超過 3 秒算同一批，停手 3 秒送出，等級 = ⌊log₂(點擊數)⌋。
  - 只按 1 下算誤觸
  - 每批送出後冷卻 30 秒
  - 長按、按住鍵盤不會連發
  - 間隔不到 0.06 秒的點擊不算
- **空站魔王**：站點變成 0 輛（或 0 位）時開始 10 分鐘討伐，20 人在場參戰就打倒。結束後留下需求紀錄。
- **統計切換**：「怒氣等級」與「點擊次數」兩種顯示。

## 執行方式

直接用瀏覽器打開 `index.html`，或用任何靜態網站伺服器提供這個檔案。

頁面會先嘗試讀取台北市 YouBike 2.0 即時 API 與 OpenStreetMap 圖磚：

- **讀得到**：用真實站點，並請求手機 GPS 定位。
- **讀不到**：自動切換成示範模式，用範例站點與空白底圖。這時拖曳地圖上的藍點，可以模擬走動。

### 用 GitHub Pages 發佈

1. 到 repo 的 Settings → Pages。
2. Source 選「Deploy from a branch」，分支選 `main`，資料夾選 `/ (root)`。
3. 存檔後，網址是 `https://patty60723.github.io/bike-fighter/`。

## 已知限制

- 即時 API 的欄位名稱與 CORS 還沒實測。如果瀏覽器擋下跨網域讀取，需要一個小後端代為轉發。
- 其他人的怒氣、討伐中的路人、全站累積數字都是模擬的，要接後端資料庫才會是真的。
- 你的紀錄只存在自己瀏覽器的 localStorage。
